# The unparsed XML form_schema of a form from ODK Central v0.6 as nested list.

**\[stable\]**

## Usage

``` r
fs_v7_raw
```

## Format

An object of class `list` of length 6.

## Source

[`form_schema`](https://docs.ropensci.org/ruODK/reference/form_schema.md)`(odkc_version = 0.7, parse = FALSE)`
