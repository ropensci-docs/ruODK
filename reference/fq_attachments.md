# A tibble of submission attachments.

**\[stable\]**

## Usage

``` r
fq_attachments
```

## Format

A tibble of submission attachments.

## Source

The output of
[`attachment_list`](https://docs.ropensci.org/ruODK/reference/attachment_list.md)
run on submissions of the test form
`system.file("extdata", "FloraQuadrat04.xml", package = "ruODK")`.
