# Tidy eval helpers

These functions provide tidy eval-compatible ways to capture symbols
(`sym()`, `syms()`, `ensym()`), expressions (`expr()`, `exprs()`,
`enexpr()`), and quosures (`quo()`, `quos()`, `enquo()`).
